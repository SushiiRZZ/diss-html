Wichtige Tools für Webentwickler

  • VS Code – Beliebter, kostenloser Code-Editor. Download
  • Git – Versionskontrolle für Projekte. Offizielle Seite
  • npm / yarn – Paketmanager für JavaScript-Projekte.
  • Browser DevTools – Entwicklertools in Chrome, Firefox, Edge etc.
  • Figma – Design- und Prototyping-Tool. Offizielle Seite
  • Postman – Testen von APIs. Offizielle Seite
  • Terminal / Konsole – Für viele Entwickleraufgaben unerlässlich.

Typischer Workflow

  1. Projekt anlegen (z.B. mit npm init oder create-react-app)
  2. Code schreiben und regelmäßig mit Git committen
  3. Lokale Tests im Browser durchführen (DevTools nutzen!)
  4. Code-Reviews im Team
  5. Deployment (z.B. auf Netlify, Vercel, GitHub Pages)
