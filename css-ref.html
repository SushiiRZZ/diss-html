Wichtige CSS-Eigenschaften

  • color – Textfarbe
  • background / background-color – Hintergrundfarbe
  • font-size – Schriftgröße
  • font-family – Schriftart
  • margin – Außenabstand
  • padding – Innenabstand
  • border – Rahmen
  • width, height – Breite, Höhe
  • display – Anzeigeart (block, inline, flex, grid, ...)
  • position – Positionierung
  • top, left, right, bottom – Position
  • z-index – Stapelreihenfolge
  • overflow – Überlaufverhalten
  • box-shadow – Schatten
  • border-radius – Abgerundete Ecken
  • transition – Übergänge
  • animation – Animationen
  • flex, grid – Layoutsysteme

Wichtige Selektoren

  • * – Alle Elemente
  • element – Alle Elemente dieses Typs (z.B. body, h1)
  • .klasse – Alle Elemente mit dieser Klasse
  • #id – Das Element mit dieser ID
  • element, element – Mehrere Elemente
  • element element – Nachfahrenselektor
  • element > element – Kindselektor
  • element + element – Direkt folgendes Element
  • [attribut] – Mit bestimmtem Attribut
  • :hover, :active, :focus – Pseudoklassen

Beispiele

Textfarbe und Hintergrund

body {
  color: #f1f1f1;
  background: #181a1b;
}

Flexbox-Layout

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

Hover-Effekt

a:hover {
  color: #61dafb;
}
