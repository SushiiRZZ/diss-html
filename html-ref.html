Wichtige HTML-Tags

  • <!DOCTYPE> – Dokumenttyp-Deklaration
  • <html> – Wurzel-Element
  • <head> – Metadaten
  • <title> – Titel der Seite
  • <meta> – Metainformationen
  • <link> – Verknüpfung zu externen Ressourcen
  • <body> – Seiteninhalt
  • <h1> bis <h6> – Überschriften
  • <p> – Absatz
  • <a> – Link
  • <img> – Bild
  • <ul>, <ol>, <li> – Listen
  • <table>, <tr>, <td>, <th> – Tabellen
  • <form>, <input>, <button> – Formulare
  • <div>, <span> – Container
  • <section>, <article>, <aside>, <nav>, <header>, <footer> – Semantische Elemente
  • <script> – JavaScript einbinden
  • <style> – CSS einbinden

Wichtige Attribute

  • id – Eindeutige Kennung
  • class – CSS-Klasse
  • src – Quelle (z.B. bei Bildern)
  • href – Zieladresse (z.B. bei Links)
  • alt – Alternativtext für Bilder
  • title – Zusätzliche Information
  • type – Typ (z.B. input, script)
  • value – Wert (z.B. input)
  • name – Name (z.B. input, form)
  • placeholder – Platzhaltertext
  • required – Pflichtfeld
  • disabled – Deaktiviert
  • checked – Vorausgewählt (Checkbox/Radio)

Beispiele

Einfaches HTML-Dokument

<!DOCTYPE html>
<html lang="de">
  <head>
    <meta charset="UTF-8">
    <title>Beispiel</title>
  </head>
  <body>
    <h1>Hallo Welt!</h1>
    <p>Das ist ein Absatz.</p>
    <a href="https://www.example.com">Ein Link</a>
  </body>
</html>

Formular

<form>
  <input type="text" name="name" placeholder="Dein Name" required>
  <button type="submit">Absenden</button>
</form>
