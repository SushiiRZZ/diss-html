Grundsyntax

  • Variablen: let, const, var
  • Funktionen: function name() { ... }
  • Bedingungen: if, else, switch
  • Schleifen: for, while, forEach
  • Objekte & Arrays: { ... }, [ ... ]
  • Kommentare: // einzeilig, /* mehrzeilig */

Wichtige Methoden & Objekte

  • console.log() – Ausgabe in die Konsole
  • document.getElementById(), querySelector() – Elemente auswählen
  • addEventListener() – Event-Handler hinzufügen
  • setTimeout(), setInterval() – Timer
  • Math – Mathematische Funktionen
  • Array-Methoden: push, pop, map, filter, reduce
  • String-Methoden: length, toUpperCase, split

Wichtige Events

  • click – Klick auf ein Element
  • input – Eingabe in ein Feld
  • submit – Formular absenden
  • mouseover – Maus über ein Element
  • keydown – Taste gedrückt
  • DOMContentLoaded – Seite geladen

Beispiele

Einfaches Event

document.querySelector('button').addEventListener('click', function() {
  alert('Button wurde geklickt!');
});

Array filtern

const zahlen = [1, 2, 3, 4, 5];
const gerade = zahlen.filter(n => n % 2 === 0);
console.log(gerade); // [2, 4]
