Was ist CSS?

CSS (Cascading Style Sheets) ist die Sprache, mit der das Aussehen von Webseiten gestaltet wird. Du kannst Farben, Abstände, Schriftarten und vieles mehr festlegen.

Beispiel:

body {
  background: #181a1b;
  color: #f1f1f1;
  font-family: Arial, sans-serif;
}
h1 {
  color: #61dafb;
}
